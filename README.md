# FlexBlox — Локальный конструктор игр в стиле Roblox

**FlexBlox** — это локальный трехмерный конструктор игр и игровой клиент, вдохновленный классическим Roblox и Roblox Studio. Инструмент позволяет настраивать внешний вид вашего персонажа, конструировать кастомные 3D-миры на сетке, сохранять их в локальное хранилище или публиковать на хост для совместной игры с друзьями по локальной сети Wi-Fi или Ethernet!

---

## 🚀 Основные возможности

1. **Главное меню (Roblox Shell):**
   * Точная визуальная и логическая копия интерфейса Roblox.
   * Выбор трех встроенных шаблонов миров:
     * **Classic Obby** — полоса препятствий с парящими блоками, лазерами, монетами и чекпоинтами.
     * **Speed Simulator** — скоростная трасса с неоновыми Emerald-ускорителями.
     * **Roblox City** — городской симулятор со стеклянным небоскребом и тайниками.
   * Встроенная **Студия Кастомизации Аватара** (настройка цвета джерси, выражения лица R6, головных уборов и никнейма).

2. **Режим Редактора (Creator Studio):**
   * Полноценная 3D сетка с возможностью размещения объектов (блоки, сферы, цилиндры, спавны, монеты, триггеры, лава).
   * Панель свойств (Инспектор): тонкая настройка названий деталей, цветов, материалов (Plastic, Wood, Metal, Glass, Neon) и триггерного текста.
   * Быстрое локальное сохранение в `localStorage` и публикация на сервер для Wi-Fi мультиплеера.

3. **Режим Игры (Game Client):**
   * Точная 3D физика персонажа на кинематических AABB коллайдерах.
   * Детализированная 3D-модель R6 аватара с классическими анимациями рук, ног и головы во время бега и прыжков.
   * Сбор монет, опасные зоны лавы (моментальный респавн), ускорители шагов, триггерные зоны с Roblox-уведомлениями.
   * **Мультиплеер со сверхнизким пингом:** Синхронизация положений, монет и анимаций по локальному сетевому каналу WebSockets.
   * **Симуляция Ботов:** Если вы играете в одиночку, в мирах будут бегать умные боты, собирающие монеты и общающиеся в чате!

4. **Мобильное и Сенсорное управление:**
   * Кастомный виртуальный джойстик на экране для планшетов и смартфонов.
   * Кнопка прыжка "JUMP" и управление камерой свайпами.
   * Предотвращение зума и системных жестов браузера для комфортного гейминга.

---

## 🛠️ Технологический стек

* **Фронтенд:** React, TypeScript, Three.js, Tailwind CSS, Lucide-React.
* **Бэкенд:** Node.js, Express, tsx (TypeScript execute runtime), esbuild (высокоскоростной бандлер сервера для Cloud Run/Standalone контейнеров).
* **Сеть/Мультиплеер:** WebSockets (`ws` библиотека) с авто-реконнектом и трансляцией лобби.

## 📦 Инструкция по запуску

Для развертывания проекта локально у себя на компьютере выполните следующие шаги:

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки (Dev Server)
Команда запустит веб-клиент и WebSocket шлюз на порту `3000`:
```bash
npm run dev
```
После запуска откройте [http://localhost:3000](http://localhost:3000) в любом браузере.

### 3. Компиляция и сборка в Production
Для сборки оптимизированного билда (клиентские ассеты соберутся в `dist/`, а TypeScript-сервер скомпилируется с помощью `esbuild` в единый файл `dist/server.cjs`):
```bash
npm run build
```

### 4. Запуск Production-сервера
```bash
npm start
```

## 📱 Как играть с друзьями по Wi-Fi / Bluetooth

Для локальной игры с телефонов, планшетов или других ноутбуков выполните следующие простые действия:

1. Убедитесь, что все устройства подключены к **одному роутеру Wi-Fi** или к одной точке доступа (может быть раздана с телефона).
2. На главном компьютере запустите FlexBlox (`npm run dev` или `npm start`).
3. Узнайте ваш локальный IP-адрес на главном компьютере (например, `192.168.1.100` в настройках сети/cmd `ipconfig`).
4. На смартфонах и других компьютерах откройте браузер и введите адрес хоста:  
   `http://192.168.1.100:3000`
5. На главном меню введите Код комнаты (например, `100`), выберите роль (Хост/Клиент) и нажмите **Connect!**
6. Вы окажетесь в одном 3D мире с друзьями! Прыгайте, собирайте золотые монеты, пишите в чат и соревнуйтесь в рекордах времени!
